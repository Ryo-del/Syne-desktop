# Syne Desktop

Десктопный клиент Syne Cloud (только Windows). Tauri 2 + React; дизайн (`styles.css`, иконки, окна входа и файлов) взят из Syne Study. Работает как Syne для iOS: тот же Cloud API (`Syne cloud/api/openapi.yaml`), тот же вход логином и паролем (`grant_type=password`).

## Что есть

- **Вход** логином и паролем аккаунта Syne. Пароль не сохраняется; refresh-токен лежит в связке ключей ОС (Windows Credential Manager).
- **Файлы:** папки, поиск по всему облаку, загрузка (кнопка и перетаскивание из системы; чанками с докачкой, sha256), скачивание, переименование, корзина, версии с восстановлением, правка текста и кода (Ctrl+S; при конфликте ваш текст сохраняется копией).
- **Чаты (Key Hub):** личные и групповые беседы, шифрование на устройства собеседника и свои, имена из справочника школы, непрочитанные, номер безопасности, блокирующее предупреждение при смене идентичности собеседника, сверка отпечатка ключа сервера колледжа для групп. Ключ устройства лежит в Windows Credential Manager.
- **Вложения в защищённых беседах:** файлы и фото шифруются отдельным ключом (формат — файл 13 документации), миниатюры фото, просмотр и сохранение с проверкой SHA-256. Ограничения размера и срока задаёт облако (`HUB_BLOB_*` в его .env).
- **Обычные облачные чаты** (текст и файлы, без сквозного шифрования) — для людей без Key Hub; поиск по точному логину. Беседа с человеком, у которого есть Hub, всегда идёт через Hub.
- **Синхронизация:** WebSocket облака (через локальный сервис) мгновенно обновляет чаты и файлы.
- **Допуск:** после входа компьютер отправляет запрос на подключение и ждёт подтверждения доверенного устройства (код сверяется глазами, Holding 48 часов). Отозванное устройство выходит из аккаунта.
- **Профиль:** аккаунт, занятое место, устройства с завершением входа; для доверенного устройства — подтверждение новых устройств, повышение, отзыв.
- **Настройки:** тема, адрес сервера.

## Устройство

| Часть | Что делает |
| --- | --- |
| `src/` | Интерфейс (React). Говорит только с локальным сервисом. |
| `cmd/syne-desktop-api`, `internal/cloud` | Локальный сервис (Go, sidecar Tauri): вход, обновление токенов, проксирование `/cloud/*` в `/api/v1/*`, загрузка и скачивание. Закрыт случайным токеном запуска и проверкой Origin. |
| `internal/hubdev` | Движок Key Hub (порт `HubEngine.swift` на Go поверх `Syne-protocol/hub`). |
| `src-tauri/` | Оболочка Tauri: запускает сервис и отдаёт интерфейсу токен. |

Клиент входит как `syne-windows`. Адрес сервера по умолчанию — `https://cloud.syne-network.ru`; меняется на экране входа («Сервер») или переменной `SYNE_CLOUD_SERVER`.

## Сборка

```sh
npm install
npm run tauri:dev      # сервис собирается автоматически
go test ./...          # тесты клиента облака
```

## Релиз (установщик .exe)

`.github/workflows/windows-build.yml` собирает Windows-установщик (NSIS) так же, как для Syne Study:
- push в `main` — тестовая сборка, установщик лежит в артефактах Actions 3 дня;
- тег `vX.Y.Z` — сборка и GitHub Release с установщиком; версия берётся из тега:

```sh
git tag v0.1.0 && git push origin v0.1.0
```

Перед сборкой проходят `go vet`, `go test` и проверка типов TypeScript. Установщик не подписан (подпись кода — отдельная настройка).
